# Maritek Solutions – Marine Equipment Supplier

A responsive React website for **Maritek Solutions FZE LLC**, inspired by the Harbor Craft example. Built with **Vite + React**.

## Features

- **Responsive layout** – Mobile, tablet, and desktop
- **Sections**: Hero, stats, about, services, product categories, featured products, contact form
- **Sticky header** with mobile hamburger menu
- **Contact form** (client-side; hook up your backend/API as needed)
- **Smooth scroll** and accessible markup

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

Build output is in `dist/`.

## Tech stack

- React 18
- Vite 5
- CSS (no framework) with custom properties and responsive breakpoints
